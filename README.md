# pemrograman_web3_itera_122140117

Aplikasi Personal Dashboard ini dibuat untuk membantu pengguna mencatat informasi penting seperti tugas, catatan, atau jadwal harian. Aplikasi ini interaktif, menyimpan data secara lokal, dan menerapkan fitur modern dari JavaScript (ES6+).

 Fitur Aplikasi:
➕ Menambahkan informasi atau catatan baru

🗑️ Menghapus catatan yang tidak diperlukan

💾 Penyimpanan data menggunakan localStorage, jadi data tetap tersimpan walaupun browser ditutup

🎨 Tampilan modern dan responsif
